# PyQuest implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a browser-only, 30-day Python course where learners write code and run it against tests in Pyodide.

**Architecture:** React owns the course interface and pure progress state. A dedicated Web Worker owns Pyodide, runs learner code, and returns typed test results. Typed curriculum data and versioned local storage keep content and persistence separate from UI components.

**Tech Stack:** Vite, React, TypeScript, CodeMirror 6, Pyodide, Vitest, Testing Library, CSS.

## Global constraints

- Load Pyodide once at app startup from the official CDN.
- Keep all learner execution in a Web Worker and recover from timeouts by replacing the worker.
- Persist XP, streak, completions, attempts, unlocks, and drafts in `localStorage`.
- Include all 30 days and boss battles on days divisible by five.
- Keep every exercise deterministic and independent of live network access.
- Do not commit, push, or modify `.env` files.

## File map

- `package.json`, Vite and TypeScript configuration: build and test tooling.
- `src/domain/types.ts`: shared curriculum, progress, and runtime types.
- `src/domain/progress.ts`: pure XP, unlock, attempt, completion, level, and streak rules.
- `src/domain/progress.test.ts`: progression behavior.
- `src/data/curriculum.ts`: all 30 lessons and challenge test data.
- `src/data/curriculum.test.ts`: content integrity checks.
- `src/storage/progressStorage.ts`: versioned parsing and persistence.
- `src/storage/progressStorage.test.ts`: malformed-data and round-trip tests.
- `src/runtime/pyodide.worker.ts`: Pyodide boot, package loading, execution, output capture, and serialization.
- `src/runtime/PythonRuntime.ts`: worker lifecycle, typed requests, timeout, and reboot.
- `src/runtime/PythonRuntime.test.ts`: lifecycle and timeout tests with a worker seam.
- `src/editor/CodeEditor.tsx`: CodeMirror lifecycle and Python extensions.
- `src/components/*`: status bar, quest log, lesson panel, controls, and terminal.
- `src/App.tsx`: app coordination.
- `src/styles.css`: responsive terminal and IDE visual system.
- `src/test/*`: browser-test setup and fixtures.
